我的量体数据

量体指引 · 各字段含义

  • 身高（cm）：赤脚靠墙站立，自头顶至地面的垂直距离
  • 体重（kg）：空腹称重，建议晨起测量
  • 颈围（cm）：喉结下方绕颈一周，松紧以能放入一指为宜
  • 肩宽（cm）：左右肩峰点之间的水平距离（后背测量）
  • 胸围（cm）：乳头水平绕胸一周，保持自然呼吸
  • 腰围（cm）：腰部最细处水平绕一周，自然放松
  • 臀围（cm）：臀部最丰满处水平绕一周
  • 衣长（cm）：自颈侧根点垂至所需衣摆位置
  • 袖长（cm）：自肩峰点经手肘至手腕骨
  • 裤长（cm）：自腰围线下垂至脚踝骨
  • 大腿围（cm）：大腿根部最粗处水平绕一周
